# Write is called again and again with no path and no content when saving a long research article

Source: [anthropics/claude-code#47189](https://github.com/anthropics/claude-code/issues/47189) - paraphrased; no text copied.

## Task input
A multi-part research request: find GPU and hosted-inference providers, whether they offer APIs and Terraform providers, and their pricing. Project instructions required results to be saved as markdown under fixed folders (raw notes, wiki, log, index).

## Trajectory
| Step | Agent thought/plan (if available) | Tool call + args | Observation/result |
|---|---|---|---|
| 1 | Agent says research is complete and it will now write the article and source notes | Write with neither a target path nor body content | Rejected: both required fields absent |
| 2..10 | not recorded | The same empty Write, repeated | The same rejection each time (the reporter's log shows 10 failures, the last one cut off) |

_Partial trace: from the reporter's pasted console output. No later steps were shared._

## Expected behavior
Write is called with a target path and the article body. For long content, it is split into a first Write followed by Edits.

## Actual behavior
At least 10 back-to-back Write calls with empty arguments, all rejected. The agent did not change its approach, and the results were not saved.

## Failure category
Primary: wrong-args (all required parameters missing)
Secondary: repeats the failing call without adapting; large-payload write

## Rubric
- Pass if: Write includes both path and content, or the agent chunks the content after the first error.
- Fail if: the empty Write is repeated.
- Partial if: it recovers only after several failures.

## Rationale
Empty arguments on large writes are a common failure in long agentic runs. This case shows the agent stuck repeating the call instead of adapting, which is easy to score.
