# Tool call written as plain-text markup instead of a structured call; step ends and the read never runs

## Task input
Long-running Code Mode work with the `build` agent, investigating a bug in a Python app (the model was about to read functions related to deployment flags).

## Trajectory
| Step | Agent thought/plan (if available) | Tool call + args | Observation/result |
|---|---|---|---|
| 1 | not recorded | `grep`, then `shell` (structured calls) | Both complete |
| 2 | Announces it will look at the two functions at the core of the bug | none; the message ends with call-shaped text such as `<parameter name="path">...` (DSML-style markers in many cases) | No tool part is created; the step closes with finish reason `stop` and the session sits idle |
| 3 | (next user turn) | same read, now as a structured call | Runs |

_Partial trace: one concrete step from the session database; the reporter counts 47 text-only markup messages that ended a step with `stop` across three sessions._

## Expected behavior
Emit tool calls only through the structured tool-call channel. Never end a step with a call written as text.

## Actual behavior
The model intermittently wrote its tool call as markup in assistant text. Because no structured call was emitted, the step finished as a normal stop, the intended read never happened, and the user had to send another turn to continue. Adding an AGENTS.md rule against the markup did not help.

## Failure category
Primary: other (tool call emitted in the wrong channel, as text)
Secondary: silent stall; malformed / mixed-dialect markup

## Rubric
- Pass if: every intended tool use is a structured call.
- Partial if: markup appears in text, but a real structured call is also emitted in the same message, so the step continues (14 such mixed cases in the reporter's data).
- Fail if: the message contains only text-form call markup and the step ends (this trajectory).

## Rationale
Complements AFE-0028 (same failure on another harness and model). The reporter's finish-reason breakdown gives a clean automatic check: a text-only markup message that finishes with `stop` is a fail.
