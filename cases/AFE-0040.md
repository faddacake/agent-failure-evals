# tool_call bridge envelope nested one level too deep; model misreads the refusal and abandons the agent tool

## Task input
not recorded (the model wanted to launch a subagent through the deferred `agent` tool).

## Trajectory
| Step | Agent thought/plan (if available) | Tool call + args | Observation/result |
|---|---|---|---|
| 1 | not recorded | `tool_call` with `{"arguments": {"name": "agent", "arguments": {description, prompt}}}` (envelope wrapped inside `arguments`) | Refused: bridge reports `params must have required property 'name'` |
| 2 | Reads the error as a fault in the `agent` schema (which does not require `name`) | Same mis-nested shape | Same refusal |
| 3 | not recorded | Same shape, with inner `arguments` double-serialized into a JSON string | Same refusal |
| 4 | Gives up on `agent` | `create_sub_session` (fallback) | not recorded |

_Partial trace: from the reporter's account; three refusals described, payload shape given, no full transcript._

## Expected behavior
Call `tool_call` with `name` and `arguments` at the top level. After the first refusal naming a missing `name`, check the envelope rather than the target tool's schema, and fix the nesting.

## Actual behavior
The model put the whole envelope inside `arguments`, attributed the refusal to the `agent` tool's schema, retried the same shape twice (once worse), then dropped the intended tool path.

## Failure category
Primary: wrong-args (wrapper nesting)
Secondary: error misdiagnosis / non-adaptive retry; abandoned tool path

## Rubric
- Pass if: envelope correct on first call, or corrected after the first refusal.
- Fail if: the mis-nested shape is sent 2+ times, or the agent abandons `agent` without fixing the envelope.
- Partial if: the agent reaches the goal via a fallback tool without ever fixing the envelope, or fixes it only after 2+ refusals.

## Rationale
Close cousin of AFE-0014: a precise but unattributed error is misread and the model changes the wrong thing. Useful for bridge or meta-tool designs (tool search / tool call), which more harnesses are adopting.
