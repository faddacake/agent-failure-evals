# Subagent calls the shell tool by its lowercase name, which does not exist, mid-task

Source: [anthropics/claude-code#104200](https://github.com/anthropics/claude-code/issues/104200) - paraphrased; no text copied.

## Task input
General-purpose and custom subagents doing ordinary coding work that involves shell commands, often long script-like ones (for example a Python heredoc). The advertised shell tool name is capitalized (`Bash`); tool names are case-sensitive.

## Trajectory
| Step | Agent thought/plan (if available) | Tool call + args | Observation/result |
|---|---|---|---|
| 1 | not recorded | `Bash` with a command | Runs normally |
| 2 | not recorded | `bash` (lowercase) with the next command, often a heredoc script | Rejected: no tool by that name; the error says names are case-sensitive and points to `Bash` |
| 3 | not recorded | `Bash` with the same command | Runs; one full extra model turn spent |

_Pattern-level trace: from the reporter's aggregate counts; no single transcript is posted._

## Expected behavior
Use the exact advertised tool name on every call, including right after a successful call and on long commands.

## Actual behavior
Across 674 subagent transcripts from one user, the subagent model called `bash` 108 times in 76 sessions. 92 of those came right after a correctly named call. The slip rate was about 6 times higher on heredoc commands than on plain ones. A second user reported about 197 such calls across 75 sessions, plus calls to other tool names that were not in that session's tool list. Each slip cost a full extra turn (median about 52k context tokens re-read).

## Failure category
Primary: nonexistent-tool (case-mismatched tool name)
Secondary: mid-task slip after correct usage; wasted turn (recovers after the error)

## Rubric
- Pass if: every shell call uses the advertised name exactly.
- Partial if: one wrong-case call, then immediate recovery on the next turn (the typical trajectory here).
- Fail if: repeated wrong-case calls after the error, or the task is abandoned.

## Rationale
A small but very frequent failure with measured cost, and a clean probe of name-exactness under long, script-like arguments. Easy to replay: advertise only `Bash` and score the emitted name over many heredoc-heavy turns.
