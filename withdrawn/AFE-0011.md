# WITHDRAWN: AFE-0011

**Status:** withdrawn in v0.2.2 (2026-10-26). This case is not part of the dataset. The ID is retired and will not be reused.

**Former title:** "Never calls image_gen, replies DONE with rc=0"
**Source:** https://github.com/openai/codex/issues/32251 (openai/codex)

## Why it was withdrawn
The source report was a false alarm. The reporter closed the issue on 2026-07-10 after inspecting the session rollouts: the gpt-5.6 models did generate the images, through the code-mode path (`tools.image_gen__imagegen` inside an `exec` JavaScript call). The files were saved as `generated_images/<session>/exec-<uuid>.png`, while the reporter's check only looked for the `call_<id>.png` names that gpt-5.5 and gpt-5.4-mini produce. The "model skipped the tool" behavior and the model comparison that supported the case do not hold, so it should not be used for grading.

The original case text is not kept here. It is available in the v0.2.1 release and earlier history of this repository.
